# Payment-first Growth and enrollment

Deployed October 23, 2026. Application commit e39ef0c; worker version 029e1da9-ea9c-4977-97b8-b7f42232b8dd. Migration 2026-10-23-payment-first-onboarding.sql applied to isolated staging and the verified production runtime branch br-restless-shape-at38e1nu.

New buyers can start $29/month/location Growth checkout without signing in, alone or bundled with a one-time stand. A pending account reserves the purchase but grants no access and sends no activation email. Verified Stripe paid subscription state grants the allowance and sends activation; email delivery failure throws for webhook retry, and recorded success prevents duplicate email on event replay. Existing active accounts must sign in and keep their passwords. Mixed Growth/stand processing retains fulfillment and order emails but skips duplicate account activation provisioning. No annual option.

After activation and sign-in, eligible accounts without completed onboarding receive one modal with Find business, Connect Google, Import information and Done steps. Selection is stored per authenticated account. Google authorization returns to the same saved setup. Import fetches profile data and review pages; completion checks connection, profile, completed review pagination and errors server-side. The dashboard is mounted after completion. Existing connected, previously imported accounts were grandfathered. No publishing endpoints or paid ranking APIs are called by onboarding.
